### Remarks

Just run it with no argument:

    ruby entry.rb

If you run it with an integer argument, you can set the number of petals:

    ruby entry.rb 10


I confirmed the following implementations/platforms:

* ruby 3.4.2 (2025-02-15 revision d2930f8e7a) +PRISM [arm64-darwin23]
* ruby 3.3.7 (2025-01-15 revision be31f993d7) [arm64-darwin23]


### Description

This program generates ASCII art that resembles a flower.


### Internals

These flowers are drawn using Bézier curves.
Each petal is created using two quadratic Bézier curves.
The number of petals, their height, and control points are randomly determined.
With just three numbers, a variety of shapes can be created.

The lines are generated using the Marching Squares technique.
Also, `entry.rb` was generated by another script specifically designed for ASCII art output.
